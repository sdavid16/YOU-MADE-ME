## 2025-10-30 - Focus Trapping & ARIA State in Canvas Game Modal Dialogs
**Learning:** In canvas-based web applications with DOM overlays (e.g. modal dialogs like taunt/pause consoles), standard keyboard navigation can cause focus to leak out of the dialog into underlying HUD/control elements, causing confusion for screen readers and keyboard users. Additionally, closing the modal without explicitly restoring focus to the trigger element or canvas breaks seamless keyboard play.
**Action:** Always maintain `aria-haspopup="dialog"` and dynamically toggle `aria-expanded="true/false"` on modal triggers. Handle `Tab`/`Shift+Tab` inside overlay containers to restrict focus cycling to interactive elements inside the dialog, and save/restore `document.activeElement` when opening/closing the overlay.
